1. Abre VS Code y presiona la combinación Ctrl + Shift + P (en Windows/Linux) o Cmd + Shift + P (en macOS) para abrir la paleta de comandos.
2. Escribe y selecciona: Java: Create Java Project...
3. En la lista de opciones que aparece, elige Build Tools y luego selecciona Maven.
4. A continuación, selecciona javafx-archetype-simple (este es el arquetipo oficial de OpenJFX).
